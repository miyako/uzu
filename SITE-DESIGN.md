# Uzu site design reference

The shared guideline is maintained in
[`miyako/local-inference-site-design`](https://github.com/miyako/local-inference-site-design/blob/main/SITE-DESIGN.md).
Uzu adopts [version v1.0.0](https://github.com/miyako/local-inference-site-design/blob/v1.0.0/SITE-DESIGN.md).

This is a documentation reference, not a submodule or build dependency.
Guideline updates are adopted explicitly alongside local implementation changes.
This maintenance document is excluded from generated GitHub Pages output.

Local implementation: [stylesheet](site/style.css),
[overview template](site/index.html), and [integration guide](site/guide.html).
See [site maintenance instructions](site/README.md) for the existing build.

There are no local design exceptions beyond permitted engine-specific content
and branding: Uzu retains its green accent, logo, Apple Silicon requirements,
and truthful catalog/Hugging Face/local-model-directory semantics.
