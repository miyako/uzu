# Native server installation

Install the Apple Silicon `cli` and its accompanying provenance/licenses from a
`server-*` [native release](https://github.com/miyako/uzu/releases) into this
directory, or copy a local source build here. The executable must be
`uzu/Resources/bin/macOS/cli`, not inside another directory.

Requires macOS 26.4+ and an Apple GPU. Native binaries are not tracked in Git.
The component Publish workflow installs a checksummed release automatically.
See the [build guide](../../../../docs/native-builds.md).
